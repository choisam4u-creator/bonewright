# Test assets

- `quaternius_adventurer.glb` — "Adventurer" by Quaternius, **CC0 1.0** (Public Domain).
  Source: https://poly.pizza/m/5EGWBMpuXq (Quaternius, https://quaternius.com). A skinned game character (armature,
  24 animations, a backpack and fingers, T-pose), used as a real-shape regression test. Attribution is not required;
  it is kept as a thank-you.
- The procedural capsule doll and dog are built by `bonewright/bpy_scripts/make_test_mesh.py` (no asset file).

Benchmark assets are not in the repository; `python3 scripts/fetch_bench_assets.py` downloads them from where they
are published and writes their sources and licences to `bench-assets/ATTRIBUTION.md`.

## 한국어

  (Quaternius, https://quaternius.com). 스킨된 게임 캐릭터(아마추어·애니메이션 24개·가방·손가락, T 포즈)로 실제 형태 회귀
  시험에 쓴다. 저작권 표기는 의무가 아니지만 감사의 뜻으로 남긴다.

`bench-assets/ATTRIBUTION.md` 에 적는다.
