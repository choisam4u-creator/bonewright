v0.2 후보(우선순위)

  1. 팔 맞춤 정확도: 분석에 팔 축(어깨→팔끝) 점열과 굵기를 넣고, 손 본은 팔끝 안쪽으로 클램프. 판정 실패 시 1회 자동 재맞춤(재판정 포함 +5.7만 토큰).
  2. 사족(quadruped) 실제 메시 테스트(늑대 메타리그는 생성만 확인).
  3. motion 리타겟: SOMA 30관절 → Rigify DEF 매핑표 + 회전 복사 + 베이크.
  4. 실제 캐릭터 메시(CC0)로 검증 1건, 사용자 메시로 1건.
  5. GPL 브리지 애드온(열린 Blender 세션에 결과 넣기), extensions.blender.org 규칙 준수.

합계 입력 79,677 토큰·출력 1,233·상한 $0.86. 이전(real3)보다 입력이 2.3만 늘었다 — 팔 중심선 표본(좌우 9개)과 띠 통계가 프롬프트에 들어가서다.

정직한 주석. real4 의 Codex 팔꿈치 답은 팔 중심선에서 15cm 아래(메시 밖)였다. 분석의 중심선 표본 중 2개가 몸통 옆면 정점을 섞어 잘못 나온 것을 모델이 그대로 따라간 탓이다. 결과가 통과한 것은 보정 4(표면 안쪽으로 당기기) 가 살려낸 것이다. 그 뒤 중심선 표본 결함(직선 거리 15% 필터·칸 안 이상점 제거·반지름 검사)을 고쳤고, "팔꿈치를 15cm 어긋나게 준 답"을 중심선으로 되돌리는 테스트를 추가해 mock 으로 확인했다. 실제 Codex 재실행은 하지 않았다(약 8만 토큰, 사용자 결정).

이번에 넣은 것

  1. 분석: 띠별 x 구간 분리(몸통/팔), 정점 간격 기반 임계값, 팔 중심선 표본 8~9개(어깨 관절 표본을 앞에 추가), 어깨 높이는 팔 뿌리에서.
  2. 맞춤 보정 5단계(토큰 0): ① 팔꿈치·손목을 중심선으로 ② 손가락·발가락·뒤꿈치가 손·발 본을 따라 이동(전에는 메타리그 기본 위치에 남아 메시 밖에 떴다 — real3 판정 실패의 진짜 원인) ③ 손가락이 손끝을 넘으면 축소 ④ 남은 점을 표면 1.2cm 안쪽으로 ⑤ 사슬 다시 붙이기(Rigify "disjoint" 방지).
  3. 판정 렌더: 반투명 엑스레이 — 안쪽 본이 비쳐야 비율을 판단할 수 있다.
  4. bw demo <run_id>: IK 컨트롤(hand_ik·foot_ik·torso·head)을 움직여 96프레임 mp4/gif. macOS Blender 5.2 는 FFMPEG 출력이 빠져 있어 PNG → ffmpeg 로 합친다.
  5. 테스트 메시 결함 2개 수정(팔 캡슐 회전 부호 → 지그재그 팔, 골반 높이). 테스트 4개(리그·팔꿈치 되돌리기·BVH·게이트) 통과.

남은 약점

  • 어깨 관절 표본이 실제보다 4cm 낮게 잡힌다(겨드랑이 정점이 첫 칸에 섞임). 변형에는 큰 영향 없지만 v0.2 에서 손본다.
  • 손가락은 "손 안에 들어가게 축소"만 했다. 손가락이 있는 실제 캐릭터 메시에서는 손가락별 맞춤이 필요하다.
  • 실제 캐릭터 메시(CC0)로는 아직 검증하지 않았다. 테스트 자산은 캡슐 인형이다.
