1부 · 골반 19%에 사람 가정이 섞였나

결론: 섞여 있었다. 다만 리깅이 아니라 자(측정) 쪽이었다.

Rigify는 늑대 척추를 두 사슬로 쪼개면서 DEF 본 번호를 한 칸 민다. DEF-spine.003이 메타리그 spine.003일 거라고 본 게 사람 메타리그에서만 맞는 가정이었다. 실제 골반은 DEF-spine.004다.

고친 뒤 골반 19.0% → 15.9%, 사족 전체 13.8% → 13.5%. 기대보다 작다. 남은 15.9%는 진짜 배치 오차다.

어떻게 확인했나

목표를 하나도 주지 않고 리그를 생성해서, 메타리그 본과 DEF 본을 번호끼리 맞대봤다.

메타 spine     y=2.533  →  DEF-spine.001  y=2.533   ← 한 칸 밀림
메타 spine.001 y=2.057  →  DEF-spine.002  y=2.057   ← 한 칸 밀림
메타 spine.002 y=1.462  →  DEF-spine.003  y=1.462   ← 한 칸 밀림
메타 spine.003 y=1.075  →  DEF-spine.004  y=1.075   ← 골반은 여기
메타 spine.004 y=1.075  →  DEF-spine.004  y=1.075   ← 여기부터 번호 일치

spine~spine.003은 밀리고, spine.004부터는 맞는다. 늑대 척추가 꼬리 사슬과 몸통 사슬로 나뉘기 때문이다.

남은 골반 오차는 진짜다

오차를 방향별로 갈라 보면 앞뒤(dy) 15.8%, 높이(dz) 8.4%다. 그리고 체형에 따라 갈린다.

무리골반 앞뒤 오차해석
늑대·여우·개(4종)22.8 ~ 37.4%우리 골반이 꼬리 쪽으로 너무 밀린다
말·소·사슴·알파카(7종)0.2 ~ 13.9%괜찮다

메타리그가 늑대인데 정작 늑대·개 체형에서 더 나쁘다. 몸 길이 맞추기가 발끝~발끝 기준이라, 꼬리가 길고 몸이 짧은 개과에서 척추 뒷부분이 과하게 늘어나는 것으로 보인다. 아직 확인 안 했다.

2부 · 오픈소스 기준으로 완성도는 얼마나 되나

결론: "혼자 쓰는 실험 도구"로는 잘 굴러가고, "남이 쓰는 오픈소스"로는 아직 초입이다.

냉정하게 공개 준비의 30~40% 정도로 본다. 엔진은 돌아가는데 바깥 껍데기가 거의 없다.

가장 큰 구멍은 문서나 CI가 아니다. 이 프로젝트의 핵심 주장("Codex가 판단한다")이 최근 숫자에서 한 번도 검증되지 않았다는 점이다.

공개한다면 지금 무슨 일이 생기나

  1. 설치에서 절반이 막힌다. Blender 5.2 + Codex CLI + 로그인 + (선택) kimodo.cpp 빌드가 필요한데, Linux·윈도우는 확인된 적이 없다.
  2. 첫 실행에서 기대가 깨진다. 사람 비율 T포즈가 아니면 결과가 나쁜데, 나쁘다고 알려주는 장치가 없다. 로봇을 넣으면 238cm 어긋난 리그를 아무 경고 없이 내놓는다.
  3. 비용을 예측 못 한다. 리그 1건에 8만 토큰 안팎, 상한 $1 내외. README에 규모는 적혀 있지만 실패했을 때 얼마가 날아가는지는 안 적혀 있다.

공개까지 최소로 해야 할 것

  1. 비인간·양식화 거절 게이트. 나쁜 결과를 조용히 내놓지 않는 것이 1순위다. 정확도 개선보다 먼저다.

  3. Linux 확인 + CI(mock 테스트만 돌려도 충분하다. 40초짜리다).
  4. 영어 사용자 문서 — 한계와 비용을 먼저 적을 것.
  5. 벤치 자산 받는 스크립트(파일 대신 내려받는 링크 + 라이선스 표기).
