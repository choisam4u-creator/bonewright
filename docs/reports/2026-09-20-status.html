bonewright — 지금까지 끝난 것과 안 끝난 것

2026-09-20 · 저장소 choisam4u-creator/bonewright · 비공개 유지 중
한 줄 결론: 코드·검증·문서·CI·라이선스는 공개해도 되는 상태고, 오늘 빠져 있던 보여 줄 그림까지 채웠다. 남은 건 “공개로 바꿀지”라는 결정 하나뿐이며 그건 내가 못 한다.

1. 성능 — 숫자로 확인된 것

항목점수어떻게 쟀나
리깅 성공률63 / 66 = 95.5% scripts/bench_score.py가 자산 폴더를 훑어 정해진 순서(--from-skeleton → 실루엣 → --from-shape)를 그대로 시도. 자산도 경로도 손으로 고르지 않는다
동작 리타겟 성공률25 / 29 = 86.2% 걷기 BVH를 얹고 메시가 6배 넘게 늘어나지 않는지 확인. 본이 4개 미만 매핑된 건은 제외
관절 오차 (사람형)1.6 ~ 7.4%원저작자 뼈대와 대조. 마네퀴니 1.6%
Codex 실제 호출 정확도3.3% → 1.7%발끝·손끝 데이터를 모델에 주고 재측정(실제 유료 호출 2회)

동작 점수의 분모를 같이 봐야 한다. 리깅에 성공한 63건 중 34건은 애초에 동작을 받을 수 없다 — 모양에서 만든 사슬 리그는 본 이름이 Limb3_2 같아서 BVH가 얹히지 않는다. 이전 버전은 이걸 “성공”으로 세서 32개 자산이 1.00배(=전혀 안 움직임)로 만점을 받았다. 지금은 뺀다.

2. 이번 회차에 실제로 고친 것

#한 일결과
①메시 끝(발끝·손끝)에서 얇게 한 겹 떠서 모델에 좌표로 준다 (analyze.py)관절 오차 3.3% → 1.7%
②프롬프트(한/영)에 “빠뜨린 본은 랜드마크로 채운다”를 명시모델이 모르면 안 답하는 쪽이 더 안전해짐
③fill_missing_targets — 모델이 뺀 본을 기본값이 아니라 계산값으로 채움메타리그 기본값이 남는 사고 차단
④--map — 사용자가 BVH 본 이름을 직접 맞춰 줄 수 있게오타는 무시하고 몇 개 적용됐는지 보고
⑤가중치 새는 것 잡기: 복셀 최단거리로 “몸을 뚫고 가는” 가중치 제거, 안 쓰는 본(가슴·사족 골반) 삭제게이트 통과 + 실제 변형 개선

3. 이번 회차의 가장 값비싼 교훈

게이트는 가만히 서 있는 캐릭터만 본다. 2026-09-19에 4개의 변경이 게이트를 전부 통과하면서 실제 변형을 망가뜨렸다. 최악은 한 자산을 3.72배 → 20.7배로 늘렸다. 넷 다 움직여 보고서야 잡혔다. 그래서 규칙을 문서에 박았다 — 가중치를 건드렸으면 동작 벤치를 돌린다.

되돌린 실패 4건(원저작자 가중치 이식 · 손가락 마디 제거 · 사람형 골반 제거 · 형태학적 닫기)은 지운 자리에 실패 기록과 실측 수치를 그대로 남겼다. 다음 사람이 같은 걸 또 시도하지 않게.

6. 남의 것 — 라이선스 처리

렌더에 쓴 캐릭터 메시는 우리 것이 아니다.

  • Mannequiny © 2020 GDQuest and contributors, CC BY 4.0 (godot-demo-projects의 mannequiny.LICENSE.md 원문을 직접 확인했다 — 추측 아님)
  • CC BY는 ⓐ귀속 ⓑ변경 사실 표기를 요구한다. 둘 다 README와 docs/media/ATTRIBUTION.md에 적었다
  • 변경한 것: 원본 뼈대와 가중치를 버리고 bonewright가 새로 만들었다. 메시 형상 자체는 그대로다
  • .glb 원본은 커밋하지 않는다. 렌더만 올린다
  • Mixamo/Adobe 자산은 계속 배제(약관이 AI 테스트 금지). Epic 자체 Fab 콘텐츠도 배제(NoAI 태그)

7. 솔직한 약점

  • 리눅스는 CI에서만 돈다. 실제 리눅스 데스크톱에서 Blender.app 없이 끝까지 돌려본 적 없다. 윈도우는 미지원
  • 동작을 못 받는 리그가 34건 — 모양 기반 사슬 리그는 이름이 표준이 아니라 BVH가 안 얹힌다. 구조적 한계
  • Codex 경로는 자산별 벤치가 없다. 실제 호출은 8회 검증됐지만 66개 자산 전수는 결정론적 경로(mock)로만 쟀다
  • 벤치의 “정답”은 한 아티스트의 리그지 해부학적 진실이 아니다. 회귀 탐지용으로 읽어야 한다
  • 걷기 GIF는 루프가 매끄럽지 않다 — 60프레임이 끝나면 자세가 튄다. 사이클 정렬을 안 했다
