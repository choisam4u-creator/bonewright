결론 먼저

1. 바로 쓸 수 있는 것 — 14개 항목, 약 16 MB, 로그인 없음

아래 항목은 전부 실제로 내려받아 확인했다(GLB 13개 14 MB + Kenney zip 2 MB). curl 한 줄로 받아지고, 로그인·API 키·약관 동의가 없다. 그중 10개는 CC0·CC-BY·MIT라서 저장소에 재배포해도 된다(CC-BY와 MIT는 표기 의무가 있다). 나머지 4개는 로컬 벤치마크용으로만 쓰고 저장소에 커밋하면 안 된다.

2. 지금 벤치마크의 진짜 빈틈은 "개수"가 아니라 "다양성"

현재 기준선(bench-baseline-20260915.md)은 Quaternius 4종뿐이고 전부 15~17 관절, 전부 같은 명명 규칙이다. 이번에 찾은 것들은 그 빈틈을 정확히 메운다.

  • 본 이름 규칙 7가지 — mixamorig:LeftArm, UpperArm.L, upperarm.l, Upperarm_l, b_LeftUpperArm_09, arm_joint_L_1, C_spine0001_bind_JNT
  • 관절 수 2 ~ 67 — 지금은 15~17뿐
  • 사족보행 — Fox(여우, 24관절). 현재 표본에 사족보행이 아예 없다
  • 함정 케이스 2종 — IK 컨트롤 본이 스킨에 섞인 리그(Godot player), 스킨이 아예 없는 강체 계층(Kenney)

3. 안 되는 것 — 명확히 선을 그었다

  • Mixamo — 공식 API 없음, 자동 다운로드는 약관 위반. 다만 three.js가 이미 재배포 중인 Mixamo 캐릭터 3종(Xbot·Michelle·Soldier)은 URL로 받을 수 있다. 로컬 전용으로만.
  • Sketchfab — 검색 API는 무인증으로 되지만(확인함) 다운로드 엔드포인트는 401. 로그인 필수.
  • Quaternius 리깅 팩 — 공식 사이트 다운로드가 itch.io로 넘어가서 curl로 직접 못 받는다. 지금처럼 이미 받아둔 것을 쓰는 게 맞다.
  • Kenney 3D 캐릭터 — CC0이고 잘 받아지지만 스키닝이 없다(노드 7개 강체 계층). 관절 오차 벤치마크의 주 표본으로는 부적합.
  • BrainStem.glb — Khronos 샘플이지만 라이선스가 Poser EULA다. 쓰지 말 것.

어떻게 확인했나

"있다더라"를 적지 않으려고 세 단계로 확인했다.

  1. HTTP 확인 — 모든 URL에 HEAD 또는 범위 GET(-r 0-2047)을 보내 상태 코드와 Content-Length를 기록했다.
  2. 본 이름 실측 — GLB는 앞부분이 JSON 청크다. 헤더 12바이트로 청크 길이를 읽고 그 JSON만 범위 요청해서 skins[].joints → nodes[].name을 뽑았다. 아래 본 이름은 전부 추측이 아니라 파일에서 읽은 값이다.
  3. 실제 내려받기 — 최종 13개는 실제로 받아서 파일 크기를 대조했다(합계 14 MB, 전부 성공).

Blender가 필요한 작업은 하지 않았다. 스키닝 가중치 품질은 확인하지 않았다 — 관절 개수와 이름, 계층만 봤다.

Blender Studio 리그는 "정답"으로 바로 못 쓴다 — 실제로 열어보고 확인함

Vincent(18 MB)를 받아 압축을 풀고 안의 본 이름을 직접 읽어봤다. 결과가 예상과 달랐다.

  • Rigify 리그가 아니다. DEF-, ORG-, MCH- 접두사가 하나도 없다(0개). 손으로 만든 커스텀 애니메이션 리그다.
  • 변형 본과 컨트롤 본이 섞여 있다. 척추 하나에 spine_1_def, spine_1_fk, spine_1_ik, spine_1_ik_ctrl, spine_1_inv, spine_1_mstr, spine_1_toon이 전부 따로 있다.
  • 즉 _def로 끝나는 본만 골라야 실제 변형 뼈대가 된다. 안 거르면 컨트롤 본까지 정답으로 세어 오차가 엉망이 된다.
  • 게다가 EYELID_DOWN_LIMIT_L 같은 얼굴 드라이버 본이 수백 개다.

결론: Blender Studio 리그 3종은 기본 벤치마크 세트에서 빼는 것을 권한다. 읽으려면 Blender가 필요하고, 정답 추출에 _def 필터라는 자산 전용 규칙이 하나 더 붙는다. 프로덕션급 리그와 비교하고 싶을 때만 별도로 다루는 게 맞다.

바로 실행할 수 있는 다운로드 스크립트

아래 URL은 전부 실제로 내려받아 확인했다(GLB 13개를 한 번에 돌려 14 MB 전량 성공, Kenney zip 2 MB는 따로 받아 내용까지 열어봄. 2026-09-15 기준). A·B등급과 C등급을 폴더로 분리해서 .gitignore 처리를 쉽게 했다.

#!/usr/bin/env bash
# bonewright 벤치마크 자산 내려받기 — 로그인·API 키 불필요
# 2026-09-15 확인. A/B 등급만 저장소에 커밋 가능, C 등급은 로컬 전용.
set -euo pipefail
ROOT="${1:-bench-assets}"
mkdir -p "$ROOT"/{a-cc0,b-ccby,c-local-only}

get() {  # get <저장경로> 
  local out="$ROOT/$1"; shift
  if [ -s "$out" ]; then echo "skip  $out"; return; fi
  curl -fsSL --retry 3 --retry-delay 2 \
       -A "bonewright-benchmark/0.1" -o "$out" "$1"
  printf 'ok    %-40s %10d B\n' "$out" "$(wc -c < "$out")"
}

TJS=https://raw.githubusercontent.com/mrdoob/three.js/dev/examples/models/gltf
KHR=https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Assets/main/Models
GDT=https://raw.githubusercontent.com/godotengine/godot-demo-projects/master/3d

# ---- A: CC0 — 재배포 자유 -------------------------------------------------
get a-cc0/robot_expressive.glb  "$TJS/RobotExpressive/RobotExpressive.glb"
get a-cc0/kira.glb              "$TJS/kira.glb"
get a-cc0/simple_skin.gltf      "$KHR/SimpleSkin/glTF-Embedded/SimpleSkin.gltf"
# Kenney zip 은 경로에 해시가 들어 있어 팩이 갱신되면 바뀐다 → 자산 페이지에서 긁어 쓴다(확인함)
KENNEY=$(curl -fsSL -A "Mozilla/5.0" https://kenney.nl/assets/blocky-characters \
         | grep -oE 'https://kenney\.nl/media/pages/assets/[^"]+\.zip' | head -1)
get a-cc0/kenney_blocky.zip "$KENNEY"

# ---- B: CC-BY / MIT — 재배포 가능, 출처·고지 표기 필수 ----------------------
get b-ccby/fox.glb            "$KHR/Fox/glTF-Binary/Fox.glb"

# ---- C: 로컬 전용 — 저장소에 커밋하지 말 것 --------------------------------
#   Mixamo(Adobe) / Ready Player Me. 로컬 평가는 되지만 재배포는 안 된다.
get c-local-only/xbot.glb          "$TJS/Xbot.glb"

get c-local-only/soldier.glb       "$TJS/Soldier.glb"

printf 'c-local-only/\n' > "$ROOT/.gitignore"

# ---- 출처 표기(CC-BY 의무) -------------------------------------------------

매퍼에 꼭 넣어야 할 4가지

  1. 접두사 제거 — mixamorig:, b_, DEF-
  2. 숫자 접미 제거 — b_LeftUpperArm_09 → LeftUpperArm
  3. 좌우 표기 4종 통일 — .L / .l / _l / Left / _L_
  4. 스킨 조인트라고 다 변형 본이 아니다 — Godot player는 MASTER, r-LEGCONTROL, r-ARMORIENT 같은 IK 컨트롤 본이 스킨 조인트 목록에 들어 있다. kira에도 target_hand_l이 있다. 이걸 정답 관절로 세면 오차가 엉뚱하게 커진다

Objaverse-XL 리깅 부분집합 (7,373개)

메타데이터 CSV(1.1 MB)만 먼저 받아서 조건에 맞는 것만 고르면 된다. 실제로 세어 본 값이다.

조건개수
전체7,373
단일 스켈레톤 트리 + 관절 40~80개 + 3 MB 미만 (인간형에 가까운 구간)2,793
단일 스켈레톤 트리 + 관절 15~40개 + 1 MB 미만 (가벼운 구간)1,837
관절 20~39개2,605
관절 60~79개 (Mixamo 밀도)2,381
HF=https://huggingface.co/datasets/Linzhan/Objaverse-XL-Rigged-Animated/resolve/main
curl -fsSL -o metadata.csv "$HF/metadata.csv"          # 1.1 MB, ODC-BY

# 단일 트리 + 관절 40~80 + 1 MB 미만 → 1,573개가 걸린다(실측). 그중 20개만 받기
mkdir -p objaverse
awk -F, 'NR>1 && $11=="true" && $9>=40 && $9<=80 && $5<1000000 {print $2}' metadata.csv \
  | head -20 | while read -r id; do
      curl -fsSL -o "objaverse/$id.glb" "$HF/glb/$id.glb"
    done
# 컬럼: $2=object_id  $5=size_bytes  $9=num_joints  $11=single_tree
# 주의: 개별 자산 라이선스는 Objaverse-XL 주석에서 따로 확인해야 한다. 재배포 금지.

직접 열어 본 2개의 본 이름은 mixamorig:Hips_01(Mixamo에 번호가 붙은 형태), joint1_2(완전 무의미)였다. 이름 기반 매핑이 통하지 않는 표본이 많다는 뜻이라, 이름에 의존하지 않는 평가 경로를 시험하기에 좋다.

Articulation-XL2.0 (48K+, CC-BY-4.0)

GLB가 아니라 전처리된 NPZ(정점·면·관절·본·스키닝 가중치)다. 메시를 직접 리깅하는 우리 파이프라인에는 바로 안 맞지만, 라이선스가 CC-BY-4.0으로 단일해서 법적으로 가장 깨끗하다. 테스트셋만 1.15 GB.

https://huggingface.co/datasets/Seed3D/Articulation-XL2.0 — meta CSV 10 MB / test 1.15 GB / train 31 GB

한계와 미확인 항목

  • 스키닝 가중치 품질은 안 봤다. 관절 개수·이름·계층만 확인했다. "관절이 있다"와 "리그가 쓸 만하다"는 다르다.
  • kira.glb의 CC0 근거는 three.js 예제 페이지 문구 하나뿐이다. 원본이 Unity Asset Store 배포물이라 재배포 전에 재확인이 필요하다. 로컬 사용은 문제없다.
  • bitmoji.glb는 라이선스 미확인이라 권장 세트에서 뺐다. 같은 폴더의 다른 자산들은 전부 .txt 출처 파일이 있는데 이것만 없다.
  • Vincent(.blend)은 열어서 본 이름까지 확인했지만, Snow와 Rain은 크기 때문에 헤더만 확인했다. 두 파일의 관절 수·본 이름은 미확인이다. CloudRig 기반이라 Rigify식 DEF- 접두사가 있을 가능성이 있지만 확인하지 않은 추정이다.
  • Ready Player Me 공개 아바타 API(models.readyplayer.me)는 이번 환경에서 도메인 자체가 해석되지 않았다. 살아 있는지 미확인이다. 세트에 넣은 것은 three.js가 재배포 중인 파일 하나뿐이다.
  • Unity-chan은 라이선스(UCL) 페이지만 열리고, 파일 내려받기가 약관 동의 화면을 거치는 구조라 curl 경로를 확인하지 못했다.
  • Kenney의 다른 3D 캐릭터 팩(Mini Characters 등)은 Blocky Characters만 열어봐서, 다른 팩에 스키닝이 있는지는 미확인이다.
  • Mixamo 약관 원문은 Adobe 페이지를 직접 인용하지 못했다. "공식 API 없음 / 원본 파일 재배포 금지"는 커뮤니티·2차 출처 기준이라 부분 미확인이다. 그래서 보수적으로 C등급(로컬 전용)으로 분류했다.
  • OpenGameArt, BabylonJS/Assets, poly.pizza 정적 URL의 리깅 모델 여부는 이번 조사에서 결론까지 가지 못했다. 추가 조사 여지가 남아 있다.
  • URL은 2026-09-15 기준이다. Kenney zip만 경로에 해시가 들어 있어 팩이 갱신되면 바뀌는데, 위 스크립트는 자산 페이지에서 매번 긁어오게 해뒀다(동작 확인함). 나머지 URL은 GitHub raw 경로라 안정적이다.
