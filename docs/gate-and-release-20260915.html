거절 게이트 + 공개 준비

2026-09-15 · bonewright · 커밋 cd507fd, 1239554

결론: 거절 게이트를 만들었고, 자산 17종에서 오판이 0건이다.

핵심은 모델을 부르기 전에 막는 것이다. 리그 한 건이 입력 8만 토큰이라, 안 될 메시를 미리 걸러내면 돈이 한 푼도 안 든다.

이어서 공개에 가장 크게 걸리던 세 가지(사용자 문서·자산 재현·CI)도 처리했다. 토큰이 드는 작업은 손대지 않고 인수인계 문서로 따로 모아 뒀다.

1. 거절 게이트

기준은 지어내지 않고 자산 17종의 분석 신호와 정답 오차를 맞춰 골랐다.

  • 팔·다리 중심선이 양쪽 다 있어야 한다 — 없으면 관절 놓을 근거가 없다
  • 가랑이·엉덩·무릎·발목을 인체 비율로 때웠으면 거절 (목만 때운 건 경고)
  • 머리가 키의 35% 초과(치비) → 거절
  • 좌우 비대칭이 키의 3% 초과 → 거절
  • 크기가 0.3~20m 밖 → 거절 (안/밖 판정 복셀이 1.2cm라 이보다 작으면 측정 자체가 무의미하다)

17종 실측 — 깔끔하게 갈린다

판정오차 범위자산
통과 71.6 ~ 7.4% mannequiny 1.6 · adventurer 3.3 · modularmen ×2 · quat_pp_43j · cesium_man · quaternius_ual(경고)
거절 910.1 ~ 276.8% rigged_figure · quat_pp_41j · godot_player · platformer · rigged_mesh · kira · alien_bug · fox · robot

잘못 거절 0, 잘못 통과 0. 경계에 있던 두 개도 맞게 갈렸다 — quaternius_ual(7.4%)은 목 폴백만 있어 경고로 통과, godot_player(26.4%)는 발목 폴백이 있어 거절.

실제 흐름 확인

$ bw rig Fox.glb --preset humanoid
[1/6] analyze: 정점 290 · 높이 0.79m
BLOCKED: 이 메시는 humanoid 프리셋에 맞지 않는다(토큰 0 으로 중단):
  - 팔 중심선 없음(L/R쪽) — 이 메시에서 팔을 못 찾았다
  - 다리 중심선 없음(L/R쪽) — 이 메시에서 다리를 못 찾았다
  - 관절을 메시에서 못 찾아 인체 비율로 때웠다: ankle, hip, knee
  그래도 돌리려면 --force, 관절을 직접 찍으려면 --pin 본=x,y,z

2/6(모델 호출) 단계에 도달하지 않는다. --force를 붙이면 경고를 찍고 그대로 진행한다. 벤치는 force=True로 돌아서 거절 대상도 계속 측정한다(회귀 탐지를 잃지 않기 위해).

2. 스스로 찾아 진행한 것

앞선 점검에서 공개를 가장 크게 막는다고 본 것부터 처리했다. 전부 토큰 0이다.

솔직히 짚을 것

CI는 검증하지 못했다. 원격 저장소가 없어서 워크플로를 실제로 돌려본 적이 없다. 파일에도 그렇게 적어 뒀다. 대신 CI가 돌릴 6개 테스트가 Blender 없이 통과하는 것은 로컬에서 확인했다 (BW_BLENDER=/nonexistent로 강제, 0.001초).

나머지 테스트 6개는 Blender가 필요해서 CI에서 안 돈다. 로컬에서 12개 전부 돌려야 한다(약 40초).

3. Codex에게 넘긴 것 (토큰 리셋 뒤)

문서: docs/HANDOFF-codex.md

  1. 사족 실제 1건 (필수) — bw rig Wolf.gltf --preset quadruped. 이 프로젝트의 핵심 주장이 사족에서 한 번도 검증된 적이 없다. 지금 숫자는 전부 mock이다. 특히 앞다리(18.2%)는 어깨가 몸 안쪽이라 기하학으로 못 잡는 지점이라, 렌더를 보는 모델이 더 나을 여지가 있다.
  2. 거절 게이트가 실제 흐름에서 도는지 — 거절 쪽은 토큰 0이라 공짜로 확인된다.
  3. 사람형 회귀 1건(여유 있으면) — real8($1.10)과 판정 비교.

하지 말라고 적어 둔 것: 벤치 28종을 실제 모델로 돌리기(건당 $1이면 $28이고, 회귀 탐지는 mock으로 충분).

4. 남은 것

  1. 사족 앞다리 18.2% — 지금 가장 큰 오차. 어깨를 발 위치로 역산할 수 없다.
  2. 리눅스 확인 — pyproject에 적어뒀지만 돌려본 적이 없다.
  3. 원격 저장소 — 아직 없다(로컬 커밋 34개). 공개는 승인이 필요한 일이라 손대지 않았다.
  4. 모션 리타게팅 — v0.2 미구현.

검증: 테스트 12개 통과(신규 거절 게이트 테스트 1개 포함). 게이트 분리는 자산 17종의 runs/b11-*/analysis.json 을 실제 preflight() 에 통과시켜 확인. 펫치 스크립트는 실제 내려받아 확인.
