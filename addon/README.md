# bonewright bridge add-on (planned, GPL-3.0-or-later)

Not built yet, and not scheduled for a particular version. Anything that does `import bpy` inside Blender must be
GPL. bonewright runs Blender headless today — through the `bpy` wheel or `Blender -b` as a child process — so no
add-on is needed to use it. A small GPL bridge add-on (a socket server for a live Blender session) is an idea for
later; if it is built it will live here under its own licence file.
