# bonewright bridge add-on (planned, GPL-3.0-or-later)

Anything that `import bpy` inside Blender must be GPL. v0.1 runs headless through the `bpy` wheel or `Blender -b`, so no add-on is needed yet. A small GPL bridge add-on (socket server for a live Blender session) is planned for v0.2 and will live here under its own license file.
